# Multiple Linear Regression

## Overview

Multiple Linear Regression extends Simple Linear Regression by using multiple independent variables to predict a continuous outcome. In this notebook, I trained a Multiple Linear Regression model using Scikit-learn to predict a company's profit based on several business-related features.

## Dataset

This implementation uses the **50_Startups** dataset.

- **Independent Variables (X):**
  - R&D Spend
  - Administration
  - Marketing Spend
  - State
- **Dependent Variable (y):**
  - Profit

## What You'll Find Here

- Encoding categorical data using One-Hot Encoding
- Splitting the dataset into training and testing sets
- Training a Multiple Linear Regression model
- Making predictions on unseen data
- Comparing predicted profits with the actual values
