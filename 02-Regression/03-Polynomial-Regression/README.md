# Polynomial Regression

## Overview

Polynomial Regression builds on Linear Regression by modelling non-linear relationships between variables. In this notebook, I used Polynomial Features with Linear Regression to better fit a dataset where a straight line was not able to accurately represent the relationship between position level and salary.

## Dataset

This implementation uses the **Position_Salaries** dataset.

- **Independent Variable (X):** Position Level
- **Dependent Variable (y):** Salary

## What You'll Find Here

- Trained a Linear Regression model for comparison
- Generated polynomial features using Scikit-learn
- Trained a Polynomial Regression model
- Compared the performance of both models through visualisations
- Predicted the salary for a new position level
