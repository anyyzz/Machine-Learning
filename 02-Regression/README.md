# Regression

## Overview

Regression is one of the fundamental techniques in supervised machine learning. It is used to predict continuous numerical values by learning the relationship between one or more independent variables and a dependent variable.

This section covers some of the most commonly used regression algorithms, starting with simple linear regression and gradually moving towards more advanced models. Each notebook documents my implementation, along with my understanding of the concepts and what I learnt while working through them.

## Topics Covered

- Simple Linear Regression
- Multiple Linear Regression
- Polynomial Regression
- Support Vector Regression (SVR)
- Decision Tree Regression
- Random Forest Regression

## What You'll Find Here

Each regression notebook includes:

- An explanation of the core concept in my own words
- A Python implementation using Scikit-learn
- Dataset preprocessing where required
- Model training and prediction
- Notes, observations, and key takeaways from the implementation
