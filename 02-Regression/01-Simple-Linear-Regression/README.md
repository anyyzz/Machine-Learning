# Simple Linear Regression

## Overview

Simple Linear Regression is one of the most fundamental supervised machine learning algorithms. It is used to predict a continuous value by modelling the relationship between a single independent variable and a dependent variable.

In this notebook, I trained a Simple Linear Regression model using Scikit-learn to predict salaries based on years of experience and to understand how a regression model learns the relationship between two variables.

## Dataset

This implementation uses the Salary_Data dataset.

- **Independent Variable (X):** Years of Experience
- **Dependent Variable (y):** Salary

## What You'll Find Here

- Splitting the dataset into training and testing sets
- Training a Simple Linear Regression model
- Predicting salaries for unseen data
- Visualising the regression line on both the training and test sets
