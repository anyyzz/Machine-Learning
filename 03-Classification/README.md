# Classification

## Overview

Classification is a supervised machine learning technique used to predict categories or classes based on the available data.

This section covers some of the most commonly used classification algorithms, starting with Logistic Regression and progressing towards different distance-based, probabilistic, and tree-based approaches. Each notebook documents my implementation, along with my understanding of the concepts and what I learnt while working through them.

## Topics Covered

- Logistic Regression
- K-Nearest Neighbours (K-NN)
- Support Vector Machine (SVM)
- Kernel SVM
- Naive Bayes
- Decision Tree Classification
- Random Forest Classification

## What You'll Find Here

Each classification algorithm includes:

- A short explanation of the concept from my perspective
- A Python implementation using Scikit-learn
- Dataset preprocessing where required
- Model training and prediction
- Notes on the key ideas and observations from each implementation
